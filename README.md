# 現代戦ストラテジー（仮）

HoI4よりはるかに短い時間（最大2時間）で遊べる、本格的な現代戦ストラテジーゲームです。ブラウザ（PC）で動きます。

このゲームの本質は **見る・削る・終わらせる** の3つです。

1. **見る**：敵は基本的に見えません。衛星・偵察ドローン・早期警戒機で見つけ、撃墜や電波妨害で相手の目をつぶし合います
2. **削る**：ミサイル・迎撃弾・予算・補給路・国債はすべて有限です。飽和攻撃で防空を使い切らせ、補給線を切り、経済を爆撃します
3. **終わらせる**：緊張期の外交、張り詰め度、戦争目的、世論、講和。国家指導者として戦争の入口と出口を決めます

## 遊び方

- 主要8か国（米・中・露・日・英・仏・独・印）から1つを選び、CPUと戦います
- 最初の最大12週は緊張期です。中小国を味方に引き込み、部隊を動かし、戦争目的を決めます
- 30秒＝1週間で進み、約4年半（240週）で終わります（最大2時間）。スペースキーで一時停止
- 地図の操作：ホイールで拡大縮小、ドラッグで移動。自分の部隊がいる拠点から隣の拠点へドラッグすると攻勢（味方の拠点なら移動）
- 勝ち方は4つ：軍事勝利／有利な講和／同盟の勝利／生存・現状維持

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に書き出し
npm run sim      # CPU同士で1ゲームを自動進行（バランス確認用）
```

- 数値バランスはすべて `src/config.ts` と `src/data/countries.ts` にまとめてあります
- 拠点・海域・空域の定義は `tools/nodes.mjs`。変えたら `npm run map` で `public/data/world.json` を作り直します
- 起伏の陰影 `public/img/relief.jpg` は `tools/build_relief.py` で作っています（入力は Natural Earth の Shaded Relief）
- `main` に push すると GitHub Actions で GitHub Pages に公開されます

## 構成

| 場所 | 中身 |
| --- | --- |
| `src/game/sim.ts` | 1日ごとの進行（張り詰め度・開戦・打撃・移動・空と海・補給・地上戦・索敵・経済・講和・終了判定） |
| `src/game/ai.ts` | CPU（緊張期の外交、攻勢、兵の集中、打撃、講和） |
| `src/game/actions.ts` | プレイヤーとCPUが共通で使う行動 |
| `src/render/map.ts` | 地図の描画（Canvas） |
| `src/ui/ui.ts` | 画面のパネルと操作 |

## 注意

この作品はフィクションです。実在の国名と地図を使っていますが、現実の出来事や特定の国の意図を表すものではありません。

地図データ：[Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン）
